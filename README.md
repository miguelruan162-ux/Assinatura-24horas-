# Primeira Venda em 24H

Landing page responsiva baseada no vídeo de referência enviado.

## Arquivos
- `index.html`: conteúdo, metadados SEO e dados estruturados.
- `styles.css`: layout responsivo para celular e desktop.
- `script.js`: ano automático no rodapé.
- `robots.txt` e `sitemap.xml`: arquivos básicos para rastreamento por buscadores.
- `favicon.svg`: ícone da página.

## Checkout
Os botões de ação levam ao checkout Cakto informado para este projeto.

## Antes de publicar
O repositório está privado. Configure uma hospedagem compatível e atualize a URL do sitemap para o domínio final. O Google pode levar algum tempo para rastrear e indexar o site; não há garantia de posição nos resultados. Confirme que você tem autorização para usar os textos, marca e materiais da oferta. A página não promete vendas ou ganhos garantidos.
